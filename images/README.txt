LuxeLiving Interiors — Image Assets
====================================

All product and hero images are loaded from Pexels (free-to-use stock photography)
via direct CDN URLs. No local image files are stored — the URLs are embedded
directly in index.html and the product data in script.js.

Image sources used:
  - Hero background:    https://images.pexels.com/photos/34688219/...
  - About section:      https://images.pexels.com/photos/27164969/...
  - Product images (8): Pexels furniture photography (see script.js PRODUCTS array)

This folder exists to satisfy the project structure requirement and can
also hold local image files if needed in the future.
